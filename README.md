## 📖 Descripción

Repositorio con el material, ejercicios y recursos del **Curso de Introducción al Desarrollo Web**, donde se aprendieron los fundamentos de **HTML5**, **CSS3**, **JavaScript**, **Git** y **GitHub**. Gracias a **Superatec** por impartir este curso y hacer posible este aprendizaje.

## 📂 Estructura del repositorio

```
Curso-Introduccion-Desarrollo-Web/
├── ejercicios/          # Ejercicios prácticos en JS y HTML
├── Módulo I ... VII     # Material del curso (PDF y PPTX)
└── Matriz Curricular    # Plan de estudios
```

### Ejercicios incluidos

- `variables.js`
- `tiposDeDatos.js`
- `operadoresDeComparacion.js`
- `operadoresLogicos.js`
- `condicionales1.js` / `condicionales2.js`
- `arrays.js`
- `domExample1.html`, `domExample2.html`, `domExample3.html`

---

## 🚀 Cómo usar

1. Clona el repositorio:
   ```bash
   git clone https://github.com/SamuelCubano/Curso-Introduccion-Desarrollo-Web.git
   ```
2. Abre los archivos en tu editor favorito.
3. Ejecuta los `.html` en el navegador o los `.js` con Node.js.
